# DevShop — notes for AI coding assistants

- Build: `SITE_URL=http://localhost:8000 python3 scripts/build.py` → `dist/`. Standard library only; keep it dependency-free.
- `data/source/free-for-dev.md` is upstream data synced weekly; don't hand-edit service entries here (fix them upstream at ripienaar/free-for-dev, following its contribution rules).
- UI lives in `static/assets/` (vanilla JS/CSS). Pages are rendered by functions in `scripts/build.py`.
- The Claude skill is in `skills/devshop-free-tiers/`; its `data/services.json` is regenerated by the build.
